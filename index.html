Features

Everything you need to
stay in control

Sixteen powerful tools built into one extension. Each feature removes distractions and puts you back in control of your YouTube experience.

5-Layer Ad Blocker

uBlock Origin-level protection with 1,800+ static and remote filter rules, scriptlet injection, and anti-adblock bypass.

1,800+ filter rules

Shorts Remover

Removes YouTube Shorts from your feed, sidebar, search results, and dedicated tab.

Attention reclaim

SponsorBlock

Skips sponsored segments, intros, outros, and filler with community-powered data. Default ON out of the box.

Community-powered

Keyword Manager

Exact-match keyword blocking — full words and phrases only, Unicode-aware, with pipe synonyms and 5,000+ keywords.

Exact-match

Fake Channel Block

Auto-blocks videos from 16 known fake/reuploading channels and 45+ name patterns, plus your own custom lists.

16 channels + patterns

Language Block

Blocks content in specific languages using Unicode script detection across 22 scripts plus Latin.

22 scripts + Latin

Audio Equalizer

5-band Web Audio API equalizer with 9 presets and per-band control from 60Hz to 12kHz.

5-band EQ

Age-Gate Bypass

Automatically bypass age verification screens, consent dialogs, and "Sign in to confirm" prompts.

Auto bypass

Live Stream Cleaner

Hide chat, super chats, member badges, and tickers during live streams.

Distraction-free

Channel Manager

Block or allow specific channels with visual overlays. Add by name, URL, or channel ID.

Block & allow lists

Watch Later Queue

Queue videos for later with a built-in playlist manager, sorted right from the search page.

Playlist manager

Scheduled Blocking

Set custom time-based schedules for when blocking is active — focus during work, relaxed on weekends.

Custom schedules

Podcast Mode

Listen Mode, Sleep Timer (15–60 min), Auto Podcast EQ, and Keep Screen Awake via Wake Lock.

Listen Mode + Sleep Timer

Cloud Sync

End-to-end encrypted cloud backups with persistent sign-in. Settings survive restarts and sync across devices.

E2E encrypted

Content Density Meter

Analyzes video metadata for a quality score, with a rolling 20-video window and color-coded badges.

Quality scoring

Monetization Badge

Detects channel monetization status with 7 detection methods and shows a pill badge on thumbnails.

7 detection methods
How It Works

Up and running in 60 seconds

No Chrome Web Store needed. Install manually and get full control immediately.

1

Download

Download clify-v17.1.0-chrome.zip for Chrome/Chromium or clify-firefox-v17.1.0.xpi or mozilla addon store for Firefox from our GitHub repository. It's completely free and open source.

2

Extract & Load

Extract and load in Chrome (developer mode), load temporarily in Firefox, or use on Android with Kiwi/Quetta Browser.

3

Browse Freely

Browse YouTube with full control — configure features from the dashboard.
