Privacy Policy

Clify is built with a simple belief: your data belongs to you. Here’s exactly how we handle it.

Updated Version 17.0.0 Contact DiptoDesignStd@gmail.com

TL;DR — No Data Collection

Clify works 100% locally in your browser. No data is collected, stored externally, or sent to any servers. Your privacy is fully respected. The full breakdown is below.

1

No Data Collection Policy

Clify is designed with privacy as a fundamental principle. We believe your browsing data should remain yours alone.

What We Don’t Collect

  • No browsing history — We don’t track what you watch on YouTube
  • No personal information — We don’t collect names, emails, or account details
  • No usage analytics — We don’t track how you use the extension
  • No telemetry — The extension does not phone home
2

Local Storage Only

All data generated by Clify is stored exclusively on your local device using your browser’s storage APIs.

What’s Stored Locally

  • Blocked videos list — IDs and titles of videos you’ve blocked
  • Custom keywords — Keywords you’ve added for automatic blocking
  • Extension settings — Your preferences (theme, language, toggles)
  • Usage statistics — Local counters (videos blocked, etc.)

This data remains on your computer and is never transmitted anywhere.

3

Required Permissions

Clify requires minimal permissions to function on YouTube:

  • Access to youtube.com — To inject the content script and apply blocking
  • Storage access — To save your preferences and blocked lists locally
  • Tabs permission — To detect YouTube tabs and manage the extension icon
  • DeclarativeNetRequest — To block ad network requests at the browser level

All permissions are used solely for their intended purpose. No data is exfiltrated.

4

Open Source Transparency

Clify is 100% open source. Every line of code is available for public review on GitHub. You can:

  • Inspect exactly what data is accessed and stored
  • Verify that no hidden tracking exists
  • Build from source yourself
  • Contribute improvements or fixes
5

Third-Party Services

Clify has no embedded analytics, advertising, or tracking frameworks. The only external connections are optional and user-enabled:

  • SponsorBlock API (off by default) — Fetches community-submitted sponsored segment data if you enable SponsorBlock
  • Telegram Bot API (opt-in) — Delivers support ticket submissions if you use the contact form

Both features are fully optional and disabled until you explicitly turn them on.

6

Distribution Safety

Clify is distributed only through official channels: GitHub, Firefox Add-ons (AMO), and Chrome Web Store. All distributed packages are exact copies of the open-source codebase. There are no hidden binaries, obfuscated scripts, or proprietary blobs.

7

Your Control Over Data

You retain full control at all times:

  • View all stored data in the Clify dashboard
  • Delete individual blocked items or clear all data with one click
  • Uninstall the extension — all locally stored data is removed automatically
8

Policy Updates

If this policy changes (which would only happen if we add features requiring different data handling), the “Last Updated” date at the top of this page will be updated and changes will be noted in release notes. We will never silently change how your data is handled.

9

10

Data Security

All data is stored locally in your browser’s built-in storage, protected by the browser’s security model. It is not accessible to other websites, extensions, or third parties. Data is automatically removed when you uninstall the extension or clear browser data.

Summary — Your Privacy is Protected

Clify is designed to be a privacy-respecting YouTube blocker. We don’t collect data because we don’t need to — the extension works perfectly while keeping everything local to your browser.
