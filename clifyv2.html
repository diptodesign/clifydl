FAQ

Common Questions

Is Clify really 100% open source?

Yes. MIT license. All code on GitHub. No obfuscation. You can audit every line before installing.

How does the ad blocker work?

Three layers: (1) declarativeNetRequest blocking ~90 ad domains, (2) DOM removal targeting 120+ selectors, (3) fetch/XHR interception for 80+ tracking domains.

What is SponsorBlock?

Community-powered segment database. Clify auto-skips 9 categories: sponsors, intros, outros, self-promo, interactions, hooks, filler, previews, non-music.

What is Content Density?

Color-coded badge (cyan→red) showing real content percentage after removing sponsors, intros, filler. Aggregates per channel across videos.

Will it slow down YouTube?

Minimal. Efficient DOM observation, cached SponsorBlock data, non-blocking API calls. Everything local.

Why not on Chrome Web Store?

YouTube's policies on content blockers. Manual install ensures full transparency and zero data collection.

How do I update?

Download latest ZIP, extract, go to chrome://extensions, click Reload on Clify. Settings preserved.

Can I block channels?

Yes. Block by URL, @handle, or name. Full-screen overlay on blocked watch pages with unblock option.

Does it work on mobile?

Yes, on Kiwi Browser and Quetta Browser for Android. Load at kiwi://extensions or quetta://extensions.
