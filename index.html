Install. Open YouTube. Done.

No accounts, no configuration. Clify works from the moment you load it.

Clify monitors YouTube's DOM in real time with MutationObserver. Ads are detected and removed before they ever appear on screen.

  • Zero external filter lists needed

FAQ

Common Questions

Is Clify really 100% open source?

Yes. All code is on GitHub. No obfuscation, no tracking. You can audit every line. The only external request is to the SponsorBlock API for segment data.

How does the native ad blocker work?

Clify uses MutationObserver to detect and remove ad elements in real time as they appear in the DOM. No external filter lists needed.

What is SponsorBlock?

A community-powered database of video segments. Clify auto-skips sponsor promotions, intros, outros, and more. You can choose which categories to skip.

Will Clify slow down YouTube?

Minimal impact. Efficient DOM observation and on-demand SponsorBlock API calls. Everything runs locally in your browser.

Why isn't it on the Chrome Web Store?

Due to YouTube's policies on content blockers. Manual install ensures full transparency and zero data collection.

How do I update?

Download the latest ZIP, extract it, go to chrome://extensions and click "Reload" on the Clify card. Your settings are preserved.

Can I block specific channels?

Yes. Use the keyword filter with channel names or the dedicated Channel Blocking feature to block entire channels.

Does it work on mobile?

Yes, on Kiwi Browser and Quetta Browser for Android. Install the browser, download Clify, load it at kiwi://extensions or quetta://extensions.
